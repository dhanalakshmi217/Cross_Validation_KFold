# 🔄 Cross Validation (K-Fold)

## 📖 Overview
This project demonstrates the implementation of **K-Fold Cross Validation**, a model evaluation technique used to measure the performance and reliability of machine learning models. The dataset is divided into multiple folds, allowing the model to be trained and tested on different subsets to produce a more robust evaluation.

## ✨ Features
- Implementation of K-Fold Cross Validation
- Data preprocessing and feature scaling
- Multiple train-test iterations
- Reliable model performance evaluation
- Interactive Streamlit web application
- User-friendly interface

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## 📊 Project Workflow
1. Load and preprocess the dataset.
2. Split the dataset into K equal folds.
3. Train and evaluate the model on each fold.
4. Calculate the average performance score.
5. Display evaluation results through the Streamlit application.

## 📈 Results
The application evaluates machine learning models using K-Fold Cross Validation, providing a more reliable estimate of model performance by reducing bias caused by a single train-test split.
